the pattern beneath four bugs · one root cause

It isn't a bug. It's the architecture.

v0 · deterministic pipeline
  • Image → fixed prompt → Gemini → JSON → parse or fail.
  • No reasoning about what's in the image.
  • No memory of past tipsters or horses.
  • No mechanism to flag uncertainty.
  • When ambiguity arrives, silently corrupts.

Every fix patches one symptom. The next publication's quirk breaks it again.

v2 · agentic loop
  • Image → reason → identify → extract → flag → persist.
  • Recognises publication conventions itself.
  • Convex memory across runs (tipsters, horses, results).
  • Refuses to silently corrupt — flags ambiguity instead of guessing.

The bug class is not patched. It is structurally absent.

The pivot. This is the slide where the conversation changes. Pete stops thinking about specific bugs and starts thinking about the architecture that produces them. Don't move past this until he's nodded.
